## 3️⃣ Backend: Bug fixes (Phase 3 — Critical)

### 🐛 Fix 1: API `GET /api/Recipe/search` trả 400 do race DbContext
**File**: `backend/MenuGreen.BusinessLogicLayer/Services/RecipeService.cs` (+17/−17 dòng)

**Root cause**: `SearchAsync` dùng `Task.WhenAll` để parallel-enrich recipes, mỗi task gọi `_allergenMatching.EvaluateRecipeRiskAsync` → DB. EF Core `DbContext` không thread-safe → throw `InvalidOperationException` → controller catch → trả `BadRequest`.

**Fix**: Bỏ `Task.WhenAll`, chạy `foreach + await` sequential.

**Verification**: 6 test cases với curl (auth token) — tất cả giờ trả 200 (trước 4/6 trả 400). Đã ghi vào `docs/issues.md`.

### 🐛 Fix 2: FeatureAccessResolver lỗi khi check subscription timezone
**File**: `backend/MenuGreen.BusinessLogicLayer/Services/FeatureAccessResolver.cs` (+24/−24 dòng)

**Vấn đề**: DateTime từ DB có thể không có `Kind=Utc` → so sánh với `nowUtc` sai (đặc biệt khi so sánh `StartDate` vs `EndDate` qua giờ Việt Nam).

**Fix**: Thêm `NormalizeUtc()` helper để chuẩn hóa trước khi compare; refactor `foreach` từ LINQ filter sang inline check để dùng normalized values.
